PAKET SEO ARTIKEL - SAHABAT KACA ALUMINIUM

Isi:
- artikel.html = halaman indeks artikel
- artikel/ = 10 artikel HTML statis, masing-masing punya title, meta description, canonical, Open Graph, dan JSON-LD Article
- artikel-seo.css = styling tambahan artikel
- sitemap.xml = sitemap diperluas dengan halaman artikel

PENTING:
1. Upload artikel.html, artikel-seo.css, folder artikel/, dan sitemap.xml ke root repository.
2. Pastikan style.css, iklan.css, iklan.js, script.js, dan assets/ tetap ada.
3. Tambahkan link "Artikel" ke navigasi halaman lama jika ingin Artikel muncul di menu utama.
4. Ganti placeholder AdSense di .adsense-slot dengan kode resmi dari akun AdSense.
5. Jangan mengisi artikel dengan konten otomatis/duplikat massal. Tambahkan artikel yang benar-benar bermanfaat dan relevan.
6. Paket ini tidak mengubah admin iklan yang sudah ada.
